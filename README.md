 واجهة لوحة تحكم لوسائل التواصل الاجتماعي (Social Media Dashboard UI)
مشروع واجهة مستخدم تفاعلية ومتجاوبة مبنية باستخدام React وMaterial UI، مع تأثيرات أنيميشن احترافية باستخدام Framer Motion. الواجهة تحاكي تصميمات لوحات تحكم منصات التواصل الاجتماعي، وتحتوي على مكونات مثل البوستات، القائمة الجانبية، الوضع الليلي، وغيرها.


⚙️ مميزات المشروع
✅ تصميم متجاوب (Responsive) لجميع الأجهزة.

✅ استخدام مكتبة Material UI لتصميم واجهات احترافية.

✅ إمكانية التبديل بين الوضع الليلي والوضع الفاتح.

✅ قائمة جانبية متحركة (Sidebar) مع تأثيرات دخول.

✅ بطاقات منشورات تحتوي على زر إعجاب وحفظ.

✅ تأثير باهت للخلفية عند فتح القائمة.

✅ استخدام framer-motion في تحريك الكروت والقائمة.

🛠️ الأدوات والتقنيات المستخدمة
React.js — مكتبة لبناء واجهات المستخدم.

Material UI — مكتبة تصميم UI جاهزة ومرنة.

Framer Motion — مكتبة أنيميشن احترافية.
